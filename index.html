Configuración de Firebase (opcional)

Sin Firebase la app funciona en modo local (datos en este navegador). Para sincronizar en tiempo real entre varios PCs, ingresa los datos de tu proyecto en console.firebase.google.com y haz clic en Conectar.

¿Cómo obtener los datos de Firebase?

1. Ve a console.firebase.google.com → crea un proyecto gratis (plan Spark).
2. Abre Realtime Database → Crear base de datos → modo de prueba.
3. En Configuración del proyecto → Tus apps, registra una app web.
4. Copia los valores del objeto firebaseConfig y pégalos arriba.
