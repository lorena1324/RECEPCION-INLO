Configuración de Firebase (opcional)

Sin Firebase la app funciona en modo local (datos en este navegador). Para sincronizar en tiempo real entre varios PCs, ingresa los datos de tu proyecto en console.firebase.google.com y haz clic en Conectar.

¿Cómo obtener los datos de Firebase?

1. Ve a console.firebase.google.com → crea un proyecto gratis (plan Spark).
2. Abre Realtime Database → Crear base de datos → modo de prueba.
3. En Configuración del proyecto → Tus apps, registra una app web.
4. Copia los valores del objeto firebaseConfig y pégalos arriba.

Configura Firebase para activar la sincronización

Abre este archivo en un editor de texto y reemplaza los valores en la sección firebaseConfig con los de tu proyecto. Sigue estos pasos:

  1. Ve a console.firebase.google.com → crea un proyecto gratis (elige el plan Spark).
  2. En el proyecto, abre Realtime Database → crear base de datos → modo de prueba (30 días) o configura reglas de acceso.
  3. En Configuración del proyecto → Tus apps, registra una app web y copia el objeto firebaseConfig.
  4. Pega los valores en este archivo reemplazando TU_API_KEY, TU_PROYECTO, etc.
  5. Guarda el archivo y ábrelo en cualquier navegador — todos los PCs con el mismo archivo verán los datos en tiempo real.
